# defectdojo Provider

Terraform provider for [OWASP DefectDojo](https://github.com/DefectDojo/django-DefectDojo), the open-source vulnerability management platform. It supports and is tested against the latest patch of the two newest DefectDojo minor releases, listed under Requirements and compatibility; older versions get best-effort support only, and DefectDojo 2.x is not supported.

The provider authenticates with an API v2 token (`api_token`), or with a `username` and `password` (HTTP basic authentication), which also works when API tokens are disabled on the server. When both are set, the token is used. Most configuration objects can only be managed by a superuser.

Every attribute can also be set with an environment variable.

## Requirements and compatibility

- **DefectDojo:** the latest patch of the two newest minor releases, tested in CI: 3.4.304 and 3.5.103. Older 3.x releases get
  best-effort support; DefectDojo 2.x is not supported. Most configuration objects can only be managed by a superuser.
- **Terraform:** 1.11 or later, which the write-only attributes need (the passwords, secrets and tokens). Import by resource identity
  needs 1.12, `terraform query` with the list resources 1.14, and the `moved` block of the
  [migration from doximity/defectdojo](guides/migrating-from-doximity) 1.8. CI tests the two newest Terraform minor releases,
  1.16 and 1.17.
- **Stability:** from v1.0.0, the provider follows [semantic versioning](https://semver.org/). A change that can break a configuration
  or a state of the latest release needs a new major version; when DefectDojo removes a feature, the attributes and resources that
  manage it are deprecated first. See the [README](https://github.com/ottramst/terraform-provider-defectdojo#stability).

## Example Usage

```terraform
# Authentication with an API v2 token
provider "defectdojo" {
  url       = "https://defectdojo.example.com"
  api_token = var.defectdojo_api_token
}

# Authentication with a username and password (HTTP basic authentication),
# which also works when API tokens are disabled on the server
provider "defectdojo" {
  alias    = "basic"
  url      = "https://defectdojo.example.com"
  username = "terraform"
  password = var.defectdojo_password
}

# Every attribute can also be set with an environment variable:
# DEFECTDOJO_URL, DEFECTDOJO_API_TOKEN, DEFECTDOJO_USERNAME, DEFECTDOJO_PASSWORD
```

## Schema

### Optional

- `api_token` (String, Sensitive) The API v2 token of the user to authenticate as. Can also be set with the `DEFECTDOJO_API_TOKEN` environment variable.
- `password` (String, Sensitive) The password for HTTP basic authentication. Can also be set with the `DEFECTDOJO_PASSWORD` environment variable.
- `url` (String) The URL of the DefectDojo server, such as `https://defectdojo.example.com`, with its path if DefectDojo is served under one. Can also be set with the `DEFECTDOJO_URL` environment variable.
- `username` (String) The username for HTTP basic authentication, used when no `api_token` is set. Can also be set with the `DEFECTDOJO_USERNAME` environment variable.
